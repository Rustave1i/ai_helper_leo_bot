Использование Pydantic v2

Статус: Accepted

Контекст

Leo постоянно взаимодействует с внешними источниками данных:

Telegram Bot API;
AI-провайдеры;
SQLite;
Web Search;
внешние API.

Основная задача моделей — безопасно принимать, проверять, сериализовать и передавать структурированные данные между компонентами системы.

Решение

Во всем проекте используются модели на базе Pydantic v2 (BaseModel).

dataclass не используется.

Причины
встроенная валидация данных;
работа с JSON "из коробки";
сериализация (model_dump);
десериализация (model_validate);
строгая типизация;
единый стиль моделей во всем проекте.
Ограничения

Pydantic-модели являются только контейнерами данных.

Внутри моделей запрещается размещать:

бизнес-логику;
SQL;
обращения к AI;
обращения к Platform API;
обращения к Telegram.

Вся логика располагается только в сервисах.
