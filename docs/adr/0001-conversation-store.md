# ADR-0001 — Conversation Store

## Status

Accepted

---

## Context

Leo должен понимать длинные разговоры.
Telegram Bot API не предоставляет доступ к полной истории сообщений после добавления бота в группу.
Поэтому Leo обязан хранить собственую историю разговоров.

---

## Decision

Conversation Store использует SQLite.

Основные таблицы:

- Chats
- Users
- Messages
- MessageHistory
- Memories

Все связи между пользователями строятся через `telegram_user_id`.
Collector сохраняет события Telegram и не анализирует их.
Agent никогда не обращается к SQLite напрямую.
Доступ к данным осуществляется только через Repository.
Memory изменяется исключительно Memory Manager.

---

## Consequences

Преимущества

- Простая архитектура.
- Быстрый поиск.
- Возможность хранить историю сообщений.
- Поддержка редактирования сообщений.
- Поддержка удаления сообщений.
- Простая миграция на PostgreSQL.

Недостатки

- Требуется собственая база данных.
- Во время отключения бота сообщения не сохраняются.
